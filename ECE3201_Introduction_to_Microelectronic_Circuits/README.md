# ECE3201 — Time- and Frequency-Domain Analysis of Op-Amps

Introduction to Microelectronic Circuits project with two LTspice exercises.

- [Miller integrator](schematics/miller-integrator-1kHz.asc) transient simulations at seven input frequencies from 50 Hz to 10 kHz.
- [Non-inverting amplifier](schematics/noninverting-amplifier.asc) AC sweep using the custom [op-amp macromodel](schematics/OP-AMP.asc) and its [hierarchical symbol](schematics/OP-AMP.asy).
- [Project report](project-report.pdf) and [project specification](project-specification.pdf).

Keep the files in `schematics/` together when opening them in LTspice. Use the Miller integrator schematics for transient response and the non-inverting amplifier schematic for the AC sweep.
