# CSC1001 — Introduction to Computer Science

Python 3 assignments from CUHK-Shenzhen.

| Assignment | Exercises | Launch |
| --- | --- | --- |
| [HW 1](hw1/) | Compound interest, digit processing, integer sequences, primes, and midpoint integration | Run the named scripts in the assignment folder |
| [HW 2](hw2/) | Square-root iteration, emirps, Luhn validation, anagrams, lockers, and eight queens | Run the named scripts or import `sqrt(n)` from `q1_newton_square_root.py` |
| [HW 3](hw3/) | A `Flower` class, polynomial differentiation, and a fish-and-bear river simulation | Import `Flower` or `Polynomial`, or run `python q3_river_ecosystem.py` |
| [HW 4](hw4/) | Linked-list counting, linked-list sorting, and stack-based Tower of Hanoi | Run the individual scripts for their examples |

Each folder contains the corresponding assignment handout. Run commands from the relevant assignment directory.
