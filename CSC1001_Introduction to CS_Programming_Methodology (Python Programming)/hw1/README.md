# Homework 1

Run each file from this directory with Python 3, with `python q1_initial_account_value.py` as an example.

- [`q1_initial_account_value.py`](q1_initial_account_value.py) Enter the final account balance, annual interest rate, and number of years to calculate the initial balance.
- [`q2_print_digits.py`](q2_print_digits.py) Enter an integer to print its digits.
- [`q3_square_threshold.py`](q3_square_threshold.py) Enter an integer m to find the smallest integer whose square is greater than m.
- [`q4_exponentiation_table.py`](q4_exponentiation_table.py) Enter an integer to generate the requested sequence table.
- [`q5_list_primes.py`](q5_list_primes.py) Enter an integer to list the primes below it.
- [`q6_midpoint_integration.py`](q6_midpoint_integration.py) Enter the endpoints, the number of subintervals, and sin, cos, or tan to approximate the integral. Enter trusted values when running these original interactive scripts.
