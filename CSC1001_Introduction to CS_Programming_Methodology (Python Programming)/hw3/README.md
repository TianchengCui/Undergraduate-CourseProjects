# Homework 3

Run these examples from this directory with Python 3.

- Flower: `python -c "from q1_flower_class import Flower; print(Flower('rose', 5, 7.82).getValue())"`
- Polynomial: `python -c "from q2_polynomial_derivative import Polynomial; print(Polynomial('2*x^3+3*x^2+5*x+1').derivative())"`
- River ecosystem: python `q3_river_ecosystem.py` runs the four demonstration cases. F is fish, B is bear, and N is an empty cell.
- Custom ecosystem: `python -c "from q3_river_ecosystem import Ecosystem; Ecosystem(10, 3, 2).simulation(5)"`
