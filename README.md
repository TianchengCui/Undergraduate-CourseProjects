# Course Project

Selected coursework in programming, digital logic, analog circuits, and signal processing from CUHK-Shenzhen and UC Berkeley.

| Course | Work in this repository |
| --- | --- |
| [CSC1001](CSC1001_Introduction%20to%20CS_Programming_Methodology%20%28Python%20Programming%29/) | Four Python assignments covering numerical methods, algorithms, object-oriented programming, and data structures |
| [CSC1002](CSC1002_Computational_Lab%20%28Python%20Lab%29/) | Terminal and graphical sliding puzzles, plus a Turtle-based Snake game |
| [ECE3001](ECE3001_Signals_and_Systems/) | Speaker identification with time-domain and STFT-based features |
| [ECE2050](ECE2050_Digital_Logic_and_Systems/) | Four-bit bidirectional shift register, VHDL testbench, and simulation waveform |
| [ECE3201](ECE3201_Introduction_to_Microelectronic_Circuits/) | Time- and frequency-domain op-amp analysis in LTspice |
| [EE123](EE123_DSP/) | Frequency-domain image deblurring with adaptive Wiener filtering |
| [CS 61B](CS61B_Data_Structures/) | Spring 2026 Java homework and projects, with tests, datasets, and assignment links |

Course handouts and starter material are credited to their respective course staff. The EE123 final project was completed with Miaodi Duan.
